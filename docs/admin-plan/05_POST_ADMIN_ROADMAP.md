# 5. 상품관리 이후 웹사이트 개발 순서

관리자 상품관리 MVP가 안정된 뒤 고객용 자사몰과 주문 운영을 다음 순서로 만든다.

```text
A. 고객몰 공통 셸·SEO·카테고리
B. 상품목록·검색·필터
C. 상품상세·옵션 선택·재고 표시
D. 장바구니
E. 체크아웃·주소·배송비 계산
F. PG 결제
G. 주문 생성·결제 검증·재고 예약
H. 관리자 주문·발송
I. 취소·반품·교환
J. 회원·문의·리뷰
K. 쿠폰·할인·기획전
L. 매출·정산·분석
```

대시보드의 주문, 클레임, 문의 카드는 해당 모듈이 완성된 후에만 추가한다. 먼저 카드부터 만들고 0건으로 채우는 방식은 금지한다.
