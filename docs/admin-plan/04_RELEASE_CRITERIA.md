# 4. 배포 완료 기준

## 기능

- 상품을 초안으로 저장하고 다시 열 수 있다.
- 옵션 조합과 SKU를 만들 수 있다.
- SKU별 가격과 재고를 관리할 수 있다.
- 이미지와 상세설명을 등록할 수 있다.
- 서버 게시검증을 통과한 상품만 판매중이 된다.
- 목록 검색, 필터, 정렬, 페이지네이션이 동작한다.
- 일괄 작업과 내보내기가 동작한다.
- 카테고리, 배송, 템플릿, 공지, 연관상품, 시리즈가 실제 상품 폼과 연결된다.
- 대시보드 숫자와 목록 결과가 일치한다.
- CSV import가 staging을 거친다.

## 무결성

- 금액은 정수다.
- SKU는 매장 내 고유다.
- 품절은 재고에서 파생한다.
- 재고 변경은 이력으로 남는다.
- 상품 삭제는 보관 처리다.
- 게시된 상품 수정 충돌을 감지한다.
- 참조 중인 기준정보와 미디어를 삭제할 수 없다.

## 보안

- 사용자 세션과 역할을 서버에서 검사한다.
- RLS가 매장을 격리한다.
- service-role key는 브라우저에 없다.
- HTML을 정화한다.
- 업로드 MIME·용량·해상도를 검증한다.
- VIEWER는 write 불가다.
- 감사로그는 변경 불가다.

## 품질

- lint/typecheck/build 통과
- unit/integration/E2E 통과
- 중대 axe 오류 0
- 1440/1280/1024 조작 가능
- 10,000개 상품에서 서버 페이지네이션
- 오류, 빈 상태, 권한 없음, 세션 만료, 409 충돌 UI 존재
- 화면에 있는 버튼은 모두 동작한다.
